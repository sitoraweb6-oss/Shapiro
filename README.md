# Shapiro Legal Group — Mass Tort Law Firm Website

Premium website for **Shapiro Legal Group**, a mass tort law firm. *Justice. Built on Experience. Won Through Precision.* Built by [Sitora Web](https://sitora.org).

## About

A high-trust, editorial-style digital presence for a mass tort practice — designed to convey authority, compassion, and results. Practice areas, case results, attorney profiles, and consultation flows are presented with refined typography and cinematic motion.

## Features

- Premium editorial design with cinematic motion (GSAP, Lenis smooth scroll)
- Practice area exploration
- Case results and testimonials
- Attorney profiles
- Consultation booking / contact flows
- Fully responsive layout

## Tech Stack

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS, Radix UI, GSAP, Lenis, Motion, Lucide icons, React Hook Form
- **Build:** Next.js
- **AI:** Google Gemini AI

## Getting Started

### Prerequisites

- Node.js 18+

### Installation

```bash
npm install
npm run dev
```

The app will be available at `http://localhost:3000`.

### Build for production

```bash
npm run build
npm start
```
